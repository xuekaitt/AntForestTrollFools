# 真机调试记录（2026-11-05）

设备：Samsung SM-F741N（Galaxy Z Flip6），Android 17 / API 37，1080×2640，480dpi。
工具链：`.toolchain\jdk\jdk-17.0.21+9`、`.toolchain\sdk`（platforms;android-34 / build-tools;34.0.0）。
调试方式：`adb install` + `settings put secure enabled_accessibility_services` + `uiautomator dump` + `screencap`，截图存 `.screenshots/android/`。

## 第 1 轮：手工走查（确认可行性）

- `alipays://platformapi/startapp?appId=66666674` 可直接拉起支付宝并进入蚂蚁庄园，无需在首页找入口。
- 庄园主场景与家庭小屋是 canvas，节点树只有标题；底部导航「家庭」实际坐标约为 (437, 2385)，即 0.405 / 0.903。
- 家庭页有「跳过」推广弹层 → 关闭后出现「攒亲密度得奖励」弹层，关闭 X 为 90×87、水平居中、位于屏幕 80% 高度。
- 点「立即签到」后任务抽屉展开，任务标题与按钮在节点树中可读；当日亲密度 6 → 7。
- 抽屉任务：每日捐蛋(0/1)、请家人吃饭(0/3)、帮喂小鸡(0/1)、一起运动(0/1)、外卖红包(0/1)。
- 「一起领外卖红包福利」点击后跳到淘宝「访问被拒绝」页，不可执行且不应执行。

## 第 2 轮：v1.0.0 自动运行失败

日志：连续点击 3 个热区后结束了运行，但没有进入家庭页，也没有任何页面停留。

原因：
1. 启动走的是「打开支付宝首页 → 找蚂蚁庄园入口」，首页为 canvas，节点里没有入口文案。
2. `SceneHotspots` 的旧坐标（家庭 0.515/0.940、领饲料 0.306/0.940）与真机底部导航不符。
3. H5 尚在加载时就点击，点击落在空白画面。

修复：
- 新增 `AlipayLauncher.openManor()`，用 `alipays://platformapi/startapp?appId=66666674` 直达庄园；manifest 增加 `alipays` scheme 的 `<queries>`。
- 家庭入口改为 0.405/0.903，领饲料 0.255/0.903，饲料碗 0.575/0.690。
- 首次进入主场景等待 5 秒再点家庭入口，点击后最多重试 2 次、每次等待 9 秒。

## 第 3 轮：仍然点不进家庭页

日志：`点击热区：进入家庭小屋（第 1 次）…（第 2 次）… 连续 2 次点击后仍未进入家庭页`。

原因：`GestureTap` 使用 `resources.displayMetrics.heightPixels`，无障碍服务里该值不含底部导航栏（约 2400，而物理高度 2640），0.903 被换算成 2167，点在导航栏上方。

修复：改用 `WindowManager.maximumWindowMetrics.bounds` 取整屏尺寸，再按比例换算。

## 结论

- M1（可安装、可打开、无障碍连接）：通过。
- M2（自动进入庄园家庭页并识别任务）：通过。
- M3（自动完成一个任务并记录亲密度）：**未通过**。当天签到已由手工完成，剩余任务要么时间未到、要么需要小鸡/步数、要么属于捐赠/外部页面；安全模式下按设计不执行，因此 `todayTasks` 仍为 0。
